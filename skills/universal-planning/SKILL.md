# Universal Planning Framework

The full rulebook ships with this plugin. Read it before doing any planning work:

`${CLAUDE_PLUGIN_ROOT}/.claude/rules/universal-planning.md`

Read the whole file, then apply it. It defines:

- the 10-step planning pipeline (Discovery through Execution)
- 8 domain profiles and which sections each one pulls in
- 21 anti-patterns with concrete detection rules
- the requirement that every plan carries a measurable FAILED condition
- the C/B/A quality rubric used by `/plan-review`

The companion rubric for choosing how each phase runs is in the
[[vehicle-selection]] skill.
